# Performance

Targets (plan §24): full sync of a 2,000-file source under 5 minutes; incremental sync of 20 changed files under 30 seconds; Explore pages under 1 second at p95.
Generated by `npm run perf` (scripts/perf.ts); the numbers below are from the run recorded in `docs/perf-last-run.json`.

## How to read this
- **GitLab is faked in-process.** A real sync adds the archive download and per-commit diff requests, which will usually dominate. The parse, persist and activate path (what Lens itself controls) is what is measured.
- The synthetic repository has fewer relationships per file than a mature codebase. The harness is repeatable (`npm run perf`, `PERF_FILES=…`) so you can measure your own size class on your hardware.
- "Warm" means the immutable snapshot graph and file contents are cached in the server process; the imported-history overlay is re-read per request. "Cold" includes loading the graph (and, for packs, every file's content).
- One run on one machine: treat as order of magnitude, not a benchmark.
